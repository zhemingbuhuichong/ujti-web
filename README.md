# 天津大学专业匹配测试

一个静态、浏览器端运行的天津大学专业匹配测试项目。整体体验参考 SBTI 的答题节奏，但结果直接落到天津大学各学院，不再输出那种 MBTI 式标签。

## 项目说明

- 形式：纯静态页面，无后端、无数据库、无额外依赖
- 结构：`index.html` + `src/` 业务逻辑 + `styles/main.css` 视觉样式
- 玩法：32 道题、4 个维度、22 个公开学院结果与 2 个隐藏彩蛋结果
- 定位：适合娱乐、同学讨论、校园社交场景，不作为正式专业选择或职业规划建议

## 结果来源说明

测试结果中的学院名称和隐藏结果仅用于校园语境下的趣味匹配，不代表官方测评、招生承诺或培养结论。

## 本地运行

### 1. 运行测试

```bash
npm test
```

项目当前使用 Node.js 自带测试运行器。

### 2. 启动本地静态服务

```bash
py -m http.server 4173
```

然后在浏览器打开：

```text
http://localhost:4173
```

## 开发约束

- 保持项目为静态 / browser-only 应用
- 不引入新依赖
- 页面需要同时兼顾桌面端和移动端体验
